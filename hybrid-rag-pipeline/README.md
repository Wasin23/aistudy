# Hybrid RAG Lead Research Pipeline

**What you'll learn:**
- BM25 (keyword) + embedding (semantic) hybrid search
- Reranking with cross-encoders
- Chunking strategies and overlap
- Evaluation metrics (NDCG, MRR, precision@k)
- Data enrichment and confidence scoring
- Query decomposition and reformulation

**Tech stack:**
- Python (FastAPI)
- Weaviate/Qdrant or FAISS + BM25
- Cohere/Voyage rerankers
- OpenAI embeddings
- Real B2B datasets (Clearbit, Apollo, or web scraping)

**Why it's impressive:**
Shows you understand retrieval fundamentals, not just vector search. Hybrid + rerank is what production RAG looks like in 2026.
